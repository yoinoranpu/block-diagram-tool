# 制御ブロック線図ノート

制御工学を学ぶ学生向けの、日本語・無料・ログイン不要のWebアプリです。線図から伝達関数を求め、伝達関数から複数の等価線図を生成します。演算・保存はブラウザ内で完結します。

## 開発

Node.js 22.12以上（検証：24.19.0）、npm 11を使用します。

```sh
npm ci --cache /tmp/block-diagram-npm
npm run dev
```

Viteの開発サーバーがポート5173で起動します。クラウドの各タスクは既に隔離されているため、既存のチェックアウトを使用し、追加のGit worktreeは作りません。APIキー・データベース・外部の計算サーバーは不要です。

```sh
npm test             # 記号演算・制御系の解析解・生成検証
npm run build        # TypeScriptの型検査と静的サイト生成
npm run preview      # 本番ビルドの起動
npm run test:e2e     # 本番ビルドに対するPC／モバイル幅の操作テスト
```

E2EはPlaywrightと `/usr/bin/chromium` を使用します。別の環境では `playwright.config.ts` の実行パスをその環境のChromiumに合わせてください。モバイルテストはChromium上のiPhone相当の画面・タッチ設定です。Windows実機・iPhone実機・Safari実機での検証とは区別してください。

## 使い方

1. 「線図から伝達関数」で、例題を選ぶか「新規線図」から要素を追加します。
2. 要素の右の接続口、接続先の左の接続口の順に押すと配線できます。合流には加算点を使います。
3. 要素を選択して名前・分子・分母を編集できます。分母を空欄にすると1として計算し、線図では分子だけを表示します。分子の空欄・明示的な分母0はエラーです。ブロックの分子・分母は線図上で直接入力できます。「ブロック操作」（PCではブロックの右クリックでも表示）から左右反転・複製・削除・詳細設定を選べます。左右反転は入出力の向きの変更です。位置はドラッグまたは矢印ボタンで調整します。加算点の各配線の＋／−を押すと符号が変わります。
4. 線図より上の配線案内にある青い計算ボタンを押すと、答え、信号方程式、行列式による導出、成立条件が表示されます。別の答えとの厳密比較もできます。
5. 「伝達関数から線図」では、成立する構成だけを表示し、すべて線図から再計算して一致を確認します。生成した図は編集画面に移せます。積分器構成は生成時・整列時とも専用配置を使い、連鎖を横一列、出力を右、帰還係数を下に保ちます。

6. 「状態空間表現から」では、A・B・C・Dを入力し、伝達関数と入力行列に対応する状態変数線図を求めます。1入力1出力・状態数1〜3、文字係数・分数・直達項に対応します。状態空間入力も自動保存・専用JSONの保存読込ができます。全接続表示とラベル接続表示を切り替えられます。状態信号はx₁(s)のように下付きで表示します。詳細は [docs/状態空間表現.md](docs/状態空間表現.md) を参照してください。

自動保存はこのブラウザのlocalStorage内だけです。重要な図は「JSON保存」で書き出してください。「読込」でバージョン1のJSONを読み込めます。数式のコピーはブラウザのクリップボード権限が必要です。利用できない場合は答えのテキスト式をコピーできます。

線図は拡大・縮小・全体表示ボタン、空白のドラッグ移動、2本指の拡大縮小に対応します。PNG／SVG保存では、現在の倍率にかかわらず線図全体を出力します。加算点は白丸で表し、符号を入力線の外側に表示します。

配線チェックで未接続・二重接続を確認できます。分岐点は中央をドラッグし、左右の接続口で配線します。「線図を整える」で接続関係に沿って配置を揃えられます。20単位のグリッド吸着も用意しています。線を右クリック、または線を選択して「線の操作」から、伝達関数・分岐点・加算点を途中へ追加できます。選択した要素や線の経路を青で示します。答えの下の「基本公式でたどる計算」では、対応する直列・並列・正負帰還を段階的に整理し、各段階の等価性を再計算で確認します。

## 計算の正確性と対応範囲

- `s` と半角英字1文字の文字係数（`K`, `a`, `b`等）、整数・有限小数、四則演算・括弧・整数指数に対応します。掛け算は `*` が必要です。
- `i`, `e`, `E` は予約文字として使用不可です。関数呼び出し・暗黙の掛け算・科学表記・複数文字の係数名には未対応です。
- 入力の指数は −12〜12。12次式、文字係数、複数ループの解析解で検証しています。式全体の次数は複数因子の積で12次を超えることもあります。
- 初期値0の線形・時不変系、1入力1出力。16要素・32配線、入力式は各300文字、展開後1800項、1計算15秒を上限とし、超過はエラー表示します。
- 中核は独自の疎多変数多項式環 Q[s,K,a,…]。BigInt有理数係数で有限小数も厳密に扱います。信号方程式の分母を行ごとに払い、Bareissの分数なし消去で行列式を計算し、Cramerの公式で出力の比を求めます。
- 等価性は分母を払った差の多項式が厳密に0かで判定します。サンプル点での近似一致は使いません。一般の多変数多項式の完全な最大公約因子による約分は実装していないため、答えが未約分の場合があります。
- Nerdamer 1.1系はTeX変換・候補の因数分解に使用します。汎用simplifyは計算中核に使用しません。KaTeXは表示専用です。
- ゲイン分離と因数分解の直列構成は成立する場合だけ表示します。因数分解は展開後の分子・分母が合計400文字以内の場合に試みます。因子の実現可能性・各因子がプロパーかは別問題です。
- 積分器構成は分母1〜3次のプロパー系に対応します。分母の最高次係数で正規化し、直達項を含む可制御正準形を作ります。高次の伝達関数そのものの計算・単一ブロック生成は可能です。
- `≢ 0` はsの式として恒等的に0でないことを表します。係数の特殊な値で分母や行列式が恒等的に0になる場合は、その値を代入して再計算してください。約分で消えた入力分母の条件も保持します。
- 入出力関係の等価性と内部安定性は異なります。内部状態・最小実現・極零相殺による隠れた不安定性は検証しません。遅延・非線形系・多入力多出力は未対応です。

## 公開

`npm run build` の生成物 `dist/` を静的ホスティングに配置できます。公開操作はまだ行っていません。パッケージはビルド時に取得し、ブラウザ実行時にCDN・AI API等へ接続しません。

企画・実装範囲は [docs/企画書.md](docs/企画書.md) を参照してください。

### GitHub Pagesで公開する

公開ワークフローは `.github/workflows/pages.yml` に用意しています。

1. GitHubのリポジトリで Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。
2. `codex/control-diagram-app` ブランチのプルリクエストを作り、`main` にマージします。
3. Actions の **Publish app to GitHub Pages** が成功すると、アプリを開けます。

初回公開成功後のURLは `https://yoinoranpu.github.io/block-diagram-tool/` です。設定を変える前にワークフローが失敗した場合は、設定後に Actions からその実行を Re-run all jobs してください。以降は `main` への変更で自動更新します。リポジトリに配置したコードと設定だけでは公開完了にはなりません。

Ctrl/Cmd＋Zで図形操作を元に戻し、Ctrl/Cmd＋Shift＋ZまたはCtrl＋Yでやり直せます。選択要素はCtrl/Cmd＋C／Vで複製できます。入力欄では標準の文字編集を優先します。全角英数字や×÷等は自動変換します。保存・読込と表示・配置はそれぞれメニューにまとめています。配線の検証結果と操作メニューの説明は [docs/配線検証.md](docs/配線検証.md) を参照してください。

画面上部の紹介文を省き、ヘッダーと操作部をコンパクトにしています。将来の広告枠は作業領域の下に予約しています。広告配信はまだ行っていません。

状態変数線図の配置は自作処理を使い、入力から出力への主経路を一直線に、帰還・並列経路を上下へ配置します。伝達関数は成立する因数形を優先し、展開形も表示できます。配置と表示の仕様は [docs/線図レイアウトライブラリ.md](docs/線図レイアウトライブラリ.md) を参照してください。
