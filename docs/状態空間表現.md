# 状態空間表現からの計算

「状態空間表現から」タブで `dx/dt = Ax + Bu, y = Cx + Du` のA・B・C・Dを入力する。

## 対応範囲

- 連続時間・線形時不変・1入力1出力、状態数1〜3。初期状態は0。
- Aはn×n、Bはn×1、Cは1×n、Dは1×1。各成分は数値・文字係数・有理式。係数にsは使えない。
- 各成分300文字まで。全角英数字・演算記号は正規化。従来の記号計算と同じ係数・式の規則を使う。
- 状態数変更、2次・3次の例題、Aへの表計算の複数セル貼り付けに対応。

## 計算

`M=sI-A` として、Cramerの公式で `X/U` の各成分を求め、`G(s)=C(sI-A)^(-1)B+D` を計算する。既存の厳密有理式演算を利用し、浮動小数点の逆行列は使用しない。Web Workerで処理し、15秒で中止する。

行列係数自身の分母について成立条件を引き継ぐ。逆行列の式は `det(sI-A) != 0` の範囲で成立し、伝達関数は有理式として扱う。Aが特異でもMが有理行列として可逆なら計算できる。極零相殺や不可観測・不可制御状態を考慮すると、伝達関数だけでは内部安定性を判定できない。安定性判定・非ゼロ初期状態の応答・多入力多出力・離散時間は未実装。

## 線図

入力した行列の各状態方程式に対応する積分器・係数・白丸の加算点を表示する。初期表示は全信号を線で接続し、自作処理で主経路を一直線に配置する。ラベル接続表示も切替で利用でき、同じ状態を同一の信号ラベル（x₁、x₂、x₃、u）で接続する。伝達関数から得た別の正準形へ置き換えない。0も既定で係数ブロックとして表示する。「0を省略」「1を省略」を個別に切り替えられ、1の省略はブロックを直結線に置き換える。積分器1/sは省略しない。負号は係数ブロック内に表示する。拡大縮小、全体表示、PNG・SVG保存に対応。

## 保存

状態空間入力は既存の線図とは別のlocalStorageキーへ保存する。編集途中の空欄も保持する。JSONは `version: 1, type: "state-space", A, B, C, D` の形式で書き出し・読込できる。従来の線図JSONと混同しない。伝達関数のコピーとテキスト表示も提供する。

## 検証

2次の文字係数、3次の出力係数と直達項、密な行列、分数の文字係数、零伝達関数、特異なA、不正なサイズ・s・ゼロ分母を検証。密な3次の例は独立したSymPyの `C*(s*I-A).inv()*B+D` の結果と厳密比較している。

ブラウザではPC・iPhone相当幅で、行列編集、状態数変更、生成、再計算、全角変換、JSON往復、自動保存、入力エラー、PNG・SVG出力、横幅の維持を確認する。実機Safariでの確認とは区別する。

## 編集画面への引き継ぎ

「この線図を編集する →」で表示設定を反映した線図を編集画面へ移す。行列から作った接続・係数・積分器を引き継ぎ、3状態の全25ブロックも扱える。0の省略で入力から到達不能となった状態は、初期値0の無励振状態として除く。出力が入力から到達不能なら0の単一ブロックにする。行列入力の保存データは保持する。

## 線図・伝達関数からの逆変換

両タブの計算結果から「状態空間表現を求める」を選ぶ。連続時間SISOのプロパーな有理伝達関数を可制御正準形へ変換し、分母8次まで対応する。A・B・C・Dを構成後、Bareiss消去で行列式を求めた `C(sI−A)⁻¹B+D` と元の式を厳密比較する。行列の手入力は従来通り1〜3状態で、逆変換結果は最大8状態を表示できる。

定数は状態なし（A・B・Cは空、Dはゲイン）で表す。分子次数が分母次数を上回る式には入力微分が必要なので、通常の状態空間表現への変換不可を表示する。文字係数の最高次係数が0でない条件を明示し、その係数を0にする場合は式へ代入して再計算する。一般の多項式GCDによる完全約分は行わないため、実現が最小とは限らず、元の線図の内部状態を復元する機能でもない。

## 物理モデルの例題

「回路・力学」選択欄からRL・RC・直列RLC・質量ばねダンパを読み込める。回路例は印加電圧を入力にし、RLの出力は電流、RC/RLCの出力はコンデンサ電圧に固定している。

直列RLCは `x₁=v_C, x₂=i_L` とし、`C*dv_C/dt=i_L`、`L*di_L/dt=u-R*i_L-v_C` より `A=[[0,1/C],[-1/L,-R/L]], B=[0,1/L], C=[1,0], D=0` となる。初期値0の伝達関数は `1/(L*C*s^2+R*C*s+1)`。R・L・Cは正の物理量を想定する。入力欄の `-R/L`、`1/(L*C)` 等は数値近似ではなく文字係数の有理式として計算する。
