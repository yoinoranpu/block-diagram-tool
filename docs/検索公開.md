# 検索から利用できる公開サイトへ

本番URL：<https://yoinoranpu.github.io/block-diagram-tool/>

## サイト側で整えたもの

- トップページの日本語タイトル・説明文・canonical・検索許可・OGP・WebApplicationの構造化データ。
- 計算画面の下に静的な説明と内部リンク。使い方・対応範囲は `guide.html`、入力と保存の扱いは `privacy.html`。JavaScriptなしでも案内を読める。
- `sitemap.xml` に公開する3ページの正規URLを掲載。
- GitHub Pagesのプロジェクト階層でCSS・案内ページ・計算用Workerが動くことを検証。

構造化データは実際の機能と無料提供を記載している。架空の評価・レビューは追加しない。サイトへの広告・アクセス解析スクリプトは追加していない。

## Google Search Consoleで行うこと

所有者のGoogleアカウントによる操作が必要。サイト側の準備・公開だけでは登録完了や検索結果への掲載を意味しない。

1. <https://search.google.com/search-console/> を開き、自分のGoogleアカウントでログインする。
2. 「プロパティを追加」で **URLプレフィックス** を選び、`https://yoinoranpu.github.io/block-diagram-tool/` を入力する。GitHub管理のドメイン全体のDNS確認は選ばない。
3. 所有権確認の「HTMLタグ」を選び、表示された `<meta name="google-site-verification" content="…">` をコピーする。この公開確認タグを本番 `index.html` のheadへ追加し、デプロイが成功してからGoogle側で「確認」を押す。確認後もタグを残す。
4. 確認が終わったプロパティで「サイトマップ」を開き、`sitemap.xml` を送信する。完全なURLは `https://yoinoranpu.github.io/block-diagram-tool/sitemap.xml`。
5. 「URL検査」にトップページの完全なURLを入力し、公開URLのテスト後に「インデックス登録をリクエスト」する。必要に応じて `guide.html` も同様にリクエストする。
6. 後日、インデックス登録と検索パフォーマンスを確認する。反映には時間がかかり、掲載時期・順位は保証されない。

Googleへの認証・所有権確認はまだ行っていない。認証パスワードをリポジトリへ保存する必要はなく、必要なのはGoogleが発行した公開用の確認タグ。

## robots.txtの注意

このサイトはプロジェクト配下にある。検索エンジンがrobots.txtとして参照するのはホスト直下の `https://yoinoranpu.github.io/robots.txt` であり、`/block-diagram-tool/robots.txt` はその代わりにならない。このリポジトリでは無効な場所へrobots.txtを置かず、ページのmetaとSearch Consoleからのサイトマップ送信を使う。ホスト直下に別の設定がある場合、その設定も検索可否に影響する。

## 更新時

ページを増やしたらサイトマップとcanonicalを更新し、リンク切れを確認する。入力・保存・外部通信の実装が変わった場合はデータの扱いも更新する。検索表示が始まった後は、実際の検索語と利用者の疑問を見て説明を改善する。
