# 数式表示と入力補助

- 入力・計算・JSONは `s^3+a*s^2+b*s+1` を保持し、線図だけ `s³+a×s²+b×s+1` と表示する。
- 表示処理は文字の整形だけを行い、記号計算・式の省略・評価は行わない。分数乗や連続した累乗は曖昧な上付き文字に変えず、入力形式を保つ。
- 普通の線図では表示用の長さに合わせて文字サイズを調整する。非常に長い式は省略表示になるが、編集欄のプレビューで全体を確認できる。
- PNG・SVGは表示中のSVGから生成するので、指数と掛け算の表記も出力される。
- 電卓キーは数字・演算子・代表的な文字係数を提供する。「ほかの文字」に追加の文字係数がある。ACは選択中の分子／分母だけを消す。
- カーソル位置への挿入、選択範囲の置換、1文字削除を共通処理で行う。
- タッチ主体の端末では電卓入力を初期状態にし、inputMode=noneでソフトウェアキーボードとの重なりを避ける。通常のキーボードへも切り替えられる。実機のキーボード動作はブラウザによって異なるため別途確認する。
- カスタムキーはブロック編集と伝達関数の入力で共通。状態空間の行列入力欄は通常のキーボードを使用する。

## 確認内容

- 表示と入力の等価性、負の整数の指数、分数乗・連続した指数を不用意に変換しないこと。
- カーソル位置での挿入・選択範囲の置換・削除・クリア。
- PC・スマホでのキー入力、分子と分母の切り替え、文字係数の挿入、SVGへの表示の反映、JSON自動保存からの復元。
- スマホ390px幅の編集欄と電卓キーの表示。
