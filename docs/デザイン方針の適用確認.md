# デザイン方針の適用確認

確認日：2026-11-27

## 目的と今回の変更

制御工学を学ぶ学生が、例題または自作の線図から計算し、答えを理解する。初見の用途理解と最初の計算の発見を改善するため、ヘッダーに用途を表示し、例題→計算の案内を短くした。色・角丸・通常面とポップアップの影を共通化した。計算・配線・編集・保存の機能変更は行っていない。

継続して守る規則は [DESIGN.md](../DESIGN.md)、作業時の参照先は [AGENTS.md](../AGENTS.md)。参考先はSimulink、Desmos、diagrams.netの操作原則。最新版の実画面比較は未実施。UI UX Pro Max、Impeccable、Web Design Guidelinesのスキルは今回の利用可能一覧になかったため使用していない。

- 用途の説明、例題の入口、青い計算ボタンが見える。既存の入力→答え→計算過程の順序を維持。
- 通常のパネルの影を除き、編集画面・メニューにだけ弱い影を使用。入力と答えのパネルは役割があるため維持。
- 小画面ではタブ名と案内が折り返され、保存ボタンも次の行に回る。文字やタップ領域を縮めずに操作を維持する判断。通常のスマホより図の開始位置が下がる点は継続改善の候補。
- 例題列は既存の横スクロールを維持している。初見で残りの例題に気付くかはユーザー確認が必要。
