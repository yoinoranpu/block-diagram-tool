# 操作案内の整理

2026-11-28

## 判断

制御工学を学ぶ学生が、例題から計算し、自分の式や配線に変えて理解を確かめるサイト。毎回読む説明を増やすより、操作名と選択時のUIを入口にする。ただし図の接続口の意味など、初見では推測しづらい情報は残す。

[公式GOV.UK Detailsの公開ソース](https://github.com/alphagov/govuk-design-system/blob/main/src/components/details/index.md)で「一部だけが必要な情報は任意に表示」「多くの人が必要な情報を隠さない」を確認した。[Text inputの公式公開ソース](https://github.com/alphagov/govuk-design-system/blob/main/src/components/text-input/index.md)ではヒントを短い文にする理由と、長い説明を避ける指針を確認した。後者は入力欄向けなので、全サイトに機械的には適用していない。公式サイトとNN/gの記事の直接取得は通信制限で失敗し、今回は取得できた公式ソースを根拠にした。

| 元の案内 | 今回の扱い | 理由 |
| --- | --- | --- |
| まず例題を選んで計算 | 常設文から外す | 例題ボタンと「全体の伝達関数を求める」で操作を示せる |
| ブロックを選ぶと式を編集 | 操作ガイドへ | 既存の選択→図上編集を維持。発見しやすさは初見ユーザーで確認が必要 |
| 編集・複製・削除・位置調整の列挙 | 操作ガイドへ | 選択時に実際の操作を表示するため、未選択時の列挙を繰り返さない |
| 青い出力口→白い入力口 | 短い図記号の凡例を常設 | ボタン名だけでは分からない接続口の意味を、記号と出力／入力で示す。詳しい説明もガイドに残す |
| 次に白い入力口を選ぶ | 配線中だけ表示 | 今の操作に直接必要。読み上げ用のstatusも設定 |
| ＋／−を押して切替 | 操作ガイドへ | 図上の符号操作と、選択時の「入力符号（切替）」ボタンを維持 |

機能・計算・保存形式は変更していない。操作ガイドは通常のタップとキーボードで開閉する。単に文章を消して、操作を新しいアイコンへ置き換える対応はしていない。

## 表示の自己評価

Chromiumで撮影して画像を開き、PC1440×1000、スマホ390×844、小画面320×740を確認。

- [PC](review-images/help-desktop.png)
- [スマホ](review-images/help-mobile.png)
- [ガイドを開いたスマホ](review-images/help-mobile-open.png)
- [小画面](review-images/help-small.png)

ページ全体の横はみ出しはなし。未選択時の説明領域をなくし、図と答えの間の余白を約100px減らした。図の開始位置はPC約464px、スマホ446px、小画面505px。上部は説明を44pxのタップ可能なガイドに置き換えたため、高さ自体はほぼ変わらない。小画面では保存操作が折り返す既存の制約を維持。

ガイドを開くと図は下がる。必要なときに説明を読むための意図的な展開であり、要素の選択による位置ずれではない。閉じれば元に戻る。開いたまま配線を開始すると、配線中の案内を優先する。

## 検証と未確認

- 型チェック・ビルド成功。
- PC・スマホで既存のapp／UXテスト39件成功、対象外1件スキップ。
- 操作ガイド開閉→出力口選択→配線中の案内→中止でガイド復帰のテストを追加。
- iPhone実機Safari、Windows Edge、支援技術、初見ユーザーの発見しやすさは未確認。

次のユーザー確認では、説明せずに「ブロックの式を変更」「配線を1本追加」「負帰還の符号を変更」を頼む。迷いが続く操作にだけ、その要素の近くへ短い案内を足す。文章削減を成功指標にせず、操作の発見と完了を確認する。
