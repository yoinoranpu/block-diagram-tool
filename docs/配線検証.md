# 配線と操作の検証（2026-10-20）

公開URLは作業環境の通信制限で直接閲覧できなかったため、公開版と同じコードを本番ビルドし、ローカルのブラウザから実入力して検証した。PC幅とiPhone相当の画面幅・タッチ設定のChromiumを使用。実機Safariとは区別する。

## 検証した式

分子／分母：

- `2 / 1`
- `1 / (s+1)`
- `K / (s^2+a*s+b)`
- `K / ((s+a)*(s+b))`
- `(s+2) / (s^2+3*s+2)`
- `(s^2+2*s+3) / (s^3+3*s^2+2*s+1)`
- `1 / (s^3+2*s^2+3*s+4)`
- `(s^3+2*s+1) / (s^3+3*s^2+2*s+1)`
- `0 / (s+1)`
- `s^2 / (s+1)`
- `1 / (s^4+1)`
- `K*(s+a) / ((s+b)*(s+1))`

12式から生成できる全27パターンを、両画面幅で表示し、再計算による厳密一致と自動配線の警告がないことを確認した。並列・正負フィードバックの例題と、要素を移動した場合も別に確認した。

## 原因と変更

- 経路中央だけで評価しており、接続口の短い線をつなぐと余分な折れ曲がりが生じていた。端から端までの曲がり数で候補を比較し、直線・L字を優先する。
- 共有線の罰則が探索グリッドの細かさで増えていた。重なった長さに応じた罰則へ変更し、細かな迂回を減らす。
- 加算点の入口を強制的に別方向へ振り分けていた。同じ側から来る帰還は同じ側の異なる接続位置へ入れ、符号を分離して置く。
- 分岐位置の黒点を出力口から一定距離に仮置きしていた。同じ信号の実際の分岐位置に置く。
- 積分器構成の出力ゲインが同じ高さに並び、遠いゲインからの出力を遮っていた。段違いに配置する。

標準の並列例は必要な曲がり4か所、正負帰還例は2か所。全27生成図の曲がり数は修正前179から139へ減少した。このコーパスでは、異なる信号同士の平行な重なり、要素の貫通、配線不能の警告はいずれも0。直交する線の交差と、同じ出力からの共通配線は別に扱う。任意のユーザー配置に対して交差がなくなる保証ではない。

## 操作

- ブロック内の分子・分母へ直接入力。細かい設定は「詳細設定」。
- 分母が空欄・1・全角１・1.0・(1)の場合は分子だけの表示。
- 全角英数字・括弧・演算子、×÷、Unicodeマイナス、上付き指数を正規化。IME変換中は書き換えず、確定時に変換する。意味が曖昧な文字や暗黙の掛け算は推測しない。
- 図形選択時のCtrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y、Ctrl/Cmd+C/V。図形コピーは選択要素のみ。入力欄ではブラウザ標準の文字コピー・貼り付け・元に戻すを優先。

## ボタン整理の提案（メニュー統合は未実装）

1. 常時表示を「要素追加」「計算」「元に戻す」に絞る。
2. PNG/SVG/JSONを「保存」、拡大・整列・吸着を「表示・配置」のメニューにまとめる。
3. 複製・削除・詳細設定は要素選択時だけ表示する。式入力は図上を基本とする（この部分は実装済み）。

## 操作メニューの整理

- 「保存・読込」にPNG・SVG・JSON保存とJSON読込を集約。
- 「表示・配置」に拡大縮小・全体表示・自動整列・吸着を集約。
- 選択時の「ブロック操作」に左右反転・複製・削除・詳細設定を集約。PCのブロック右クリックからも同じメニューを表示。左右反転は入出力口の向きの変更で、式の逆数化ではない。
- スマホでは通常のタップで選択し、同じ操作メニューを利用できる。文字入力欄の右クリックはブラウザ標準のメニューを維持。
- メニューは操作後・外側のクリック・Escapeで閉じる。吸着のチェック変更ではメニューを維持する。

## 選択位置・計算ボタン・途中への追加

- 選択操作バーの高さを確保し、スマホの選択時自動拡大を廃止。クリックだけで図の表示位置・倍率が変わらないことをPC・スマホ幅で検証。
- 線図モードの計算ボタンを、配線案内の横（スマホでは案内の直下）、線図より上へ移動。
- 線を右クリック、または線を選択して「線の操作」から、伝達関数・分岐点・加算点を途中に追加。元の接続と加算点側の符号を保持。追加する伝達関数の初期値は1。
- 「線図を整える」を常時表示。座標に依存せず接続関係から主経路・並列経路・帰還経路を配置し、帰還ブロックの入出力を戻り方向に設定。複雑な線図では全交差の解消を保証せず、手動調整も可能。配置変更は元に戻せる。

## 積分器構成の専用配置と画面上部

積分器構成では、一般の主経路が6要素を超える場合のグリッド配置に落ち、出力が左へ折り返していた。接続から積分器連鎖・帰還係数・出力係数・直達項を認識する専用配置に変更し、生成時と「線図を整える」の両方で利用する。積分器は横一列、出力加算点と出力は右、帰還係数は下、出力係数は上に置く。名前・IDや元の座標に依存せず、未知の構成は一般の配置へ戻す。2次・3次・直達項を含む構成で、整列の反復、厳密な計算結果、障害物との衝突を検証する。これは配置の改善であり、極に基づく制御系の安定性判定機能ではない。
