# 制御ブロック線図ノート：初版の企画と実装

この文書は会話で提供された要件を記録したものです。別の企画書ファイルはリポジトリ内に存在しなかったため、その内容を推測してはいません。

## 目的・対象

制御工学を学ぶ学生が授業・課題・試験勉強で、答え合わせと理解に使う日本語Webアプリ。無料・ログイン不要。Windows PCとiPhoneでの利用を想定し、計算と保存をブラウザ内で行う。AI API・広告は導入しない。

中心機能は、線図から全体の伝達関数を求めることと、伝達関数から同じ入出力関係を持つ複数パターンの線図を生成すること。システム構成図・業務フロー用ではない。

## 実装済み

- 直接計算画面を開く2タブ構成。「入力→答え→計算過程・解説」の順。
- ブロック、加算点、分岐点、入力、出力の追加・選択・移動・削除・複製。ドラッグ以外に矢印ボタンで移動可能。
- 接続口を順番にクリック／タップして配線。配線の選択・削除。加算点の各入力符号を切り替え。
- 分子・分母を別々に編集する分数型エディター。数値・文字・演算子の補助キーとPCキーボード入力。
- 文字係数と高次式、直列・並列・正負帰還・複数ループの厳密演算。
- 単一ブロック、ゲイン分離、因数分解による直列、積分器による構成。成立した線図を再計算して原式と厳密比較。
- 別の伝達関数との等価性比較。成立条件、特異系、未対応、上限超過の表示。
- 線図の元に戻す／やり直す（最大60状態）。直列・並列・正負帰還・複数ループの例題。
- ブラウザ内の自動保存、JSON書き出し・読み込み、数式のコピー。
- 白・薄いグレーを基調に、青の主要ボタン・選択状態。レスポンシブ画面と横スクロール可能な線図領域。

## 技術構成

React 19 / TypeScript / Vite。SVGの編集画面。Web Workerで演算を実行し、15秒の期限でWorkerを終了する。疎多変数多項式とBigInt有理数による独自計算コア。Bareiss行列式とCramerの公式。Nerdamerで候補の因数分解・TeX化、KaTeXで数式表示。

状態はlocalStorage、持ち運びはスキーマバージョン付きJSON。サーバー保存・認証は持たない。アプリは静的配信でき、ブラウザ実行時の外部計算APIは不要。

## 初版の制限

詳細はREADMEの「計算の正確性と対応範囲」に記載。特に16要素・32配線、1入力1出力、入力300文字、指数 −12〜12、積分器生成は分母1〜3次のプロパー系、完全な多変数約分は未対応。式の等価性は未約分でも厳密に判定する。計算不能を推測値で埋めない。

## 操作改善（利用時のフィードバックを反映）

- 分子の空欄はエラーとして案内する。分母の空欄はユーザー指定の仕様として1とみなし、線図では分子だけのゲイン表示にする。分母に明示的に0を入力した場合はエラーを維持する。計算エラーにはブロック名と対象箇所を添える。
- 加算点は白丸で表し、Σを使わない。各入力線の符号は円の外に置く。
- 配線は障害物を避ける直角経路。重なりと交差にコストを設け、加算点の入力方向を分ける。実際の分岐は黒点で示す。要素が重なり迂回できない場合は警告を表示する。
- 積分器・帰還ゲイン・出力ゲインの行の間隔を広げ、帰還ゲインの入出力を左向きにする。向きの変更は信号方程式に影響しない。
- PCでは画面内の編集パネル、スマホでは下部の編集パネルを表示。分子・分母の入力のために線図の下へ移動する必要をなくす。補助キーはパネル内で開閉可能。
- 表示は初期状態で全体に合わせる。拡大・縮小・全体表示ボタン、空白部分のドラッグによる移動、2本指での拡大縮小に対応。表示倍率・移動は計算データ・JSON・元に戻す履歴に影響しない。
- PNG／SVGで線図全体を保存。表示倍率にかかわらず全体を出力し、編集用の接続口・選択枠・背景ドットを除く。iPhone実機での保存先や共有メニューは別途確認が必要。

## 改善案の実装状況

1. **配線ミスの可視化（実装済み）**：未接続、入力の二重接続、出力につながらない要素を計算前に色で示す。
2. **学習向けの計算過程（基本構成を実装済み）**：直列・並列・フィードバックの公式を使って、途中の線図を1段階ずつ表示する。行列式だけでは理解しづらい場合の導線を作る。
3. **スナップ・整列（一部実装済み）**：20単位のグリッド吸着と自動整列を用意。整列は元に戻せる。手動レーン・折れ点編集は未実装。
4. **線をたどる表示（実装済み）**：選んだ信号の経路を同じ色で強調し、入力元・出力先・加算符号を一覧表示する。色だけに依存せずラベルも付ける。
5. **数式の入力支援（今回見送り）**：入力中の整形プレビュー、括弧の閉じ忘れ表示、sの次数・係数表で入力する方式。線図内の長い式の省略も改善する。
6. **計算対象の状態表示**：最新の計算結果か、編集後で再計算が必要かを明確にし、例題読み込みや新規作成の前に作業を保護する。
7. **複数の図の保存（今回見送り）**：図に名前を付ける、保存一覧を作る、直前の版に戻す。JSON読み込み時に式入力も含めて元へ戻せるようにする。
8. **学習の拡張**：係数へ数値を代入した確認、極・零点、安定性の解説、ボード線図。伝達関数の一致と内部安定性を区別した表示を維持する。

基本公式の途中の線図は、直列・2経路の並列・単純な正負帰還に対して生成し、各段階を連立方程式で再計算して元の伝達関数との厳密一致を確認する。交差ループ等で安全に整理できない部分は残し、その旨を示す。
分岐点は左右の接続口と中央の移動範囲を分離。マウスとタッチの双方で移動できる。選択経路は青線と入力元・出力先の文字で示し、他の経路は淡くする。
