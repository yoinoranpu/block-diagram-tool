# 制御ブロック線図ノート：初版の企画と実装

この文書は会話で提供された要件を記録したものです。別の企画書ファイルはリポジトリ内に存在しなかったため、その内容を推測してはいません。

## 目的・対象

制御工学を学ぶ学生が授業・課題・試験勉強で、答え合わせと理解に使う日本語Webアプリ。無料・ログイン不要。Windows PCとiPhoneでの利用を想定し、計算と保存をブラウザ内で行う。AI API・広告は導入しない。

中心機能は、線図から全体の伝達関数を求めることと、伝達関数から同じ入出力関係を持つ複数パターンの線図を生成すること。システム構成図・業務フロー用ではない。

## 実装済み

- 直接計算画面を開く2タブ構成。「入力→答え→計算過程・解説」の順。
- ブロック、加算点、分岐点、入力、出力の追加・選択・移動・削除・複製。ドラッグ以外に矢印ボタンで移動可能。
- 接続口を順番にクリック／タップして配線。配線の選択・削除。加算点の各入力符号を切り替え。
- 分子・分母を別々に編集する分数型エディター。数値・文字・演算子の補助キーとPCキーボード入力。
- 文字係数と高次式、直列・並列・正負帰還・複数ループの厳密演算。
- 単一ブロック、ゲイン分離、因数分解による直列、積分器による構成。成立した線図を再計算して原式と厳密比較。
- 別の伝達関数との等価性比較。成立条件、特異系、未対応、上限超過の表示。
- 線図の元に戻す／やり直す（最大60状態）。直列・並列・正負帰還・複数ループの例題。
- ブラウザ内の自動保存、JSON書き出し・読み込み、数式のコピー。
- 白・薄いグレーを基調に、青の主要ボタン・選択状態。レスポンシブ画面と横スクロール可能な線図領域。

## 技術構成

React 19 / TypeScript / Vite。SVGの編集画面。Web Workerで演算を実行し、15秒の期限でWorkerを終了する。疎多変数多項式とBigInt有理数による独自計算コア。Bareiss行列式とCramerの公式。Nerdamerで候補の因数分解・TeX化、KaTeXで数式表示。

状態はlocalStorage、持ち運びはスキーマバージョン付きJSON。サーバー保存・認証は持たない。アプリは静的配信でき、ブラウザ実行時の外部計算APIは不要。

## 初版の制限

詳細はREADMEの「計算の正確性と対応範囲」に記載。特に16要素・32配線、1入力1出力、入力300文字、指数 −12〜12、積分器生成は分母1〜3次のプロパー系、完全な多変数約分は未対応。式の等価性は未約分でも厳密に判定する。計算不能を推測値で埋めない。
