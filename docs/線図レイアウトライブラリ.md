# 線図の自動配置と表示

## 調査・採用

- [ELK.js](https://github.com/kieler/elkjs) は、ノードの接続口（ポート）を指定でき、階層配置・直角配線・帰還を含むグラフを扱える。ブラウザのWeb Workerに対応する。今回、状態空間表現から作る全接続線図に **elkjs 0.12.0** を採用した。
- [Dagre](https://github.com/dagrejs/dagre) はMITライセンスの有向グラフ配置ライブラリ。今回は接続口と直角配線を明示的に扱う必要があるため、ELK.jsを選んだ。

ELK.jsには入力行列から組み立てたグラフの配置と配線のみを渡す。計算・行列入力・SVG描画は本アプリ側で行う。外部計算APIやCDNは利用しない。既存の手描き線図エディタの配線エンジンは、この変更では置き換えていない。

ELK.jsのAPIと同梱のWorkerを利用し、WorkerファイルはViteのURLアセットとして配布する。ブラウザのWorker内ではbundled版のFakeWorkerが利用できないため、公式APIからclassic Workerを起動する構成を採用した。15秒で中止し、配置できない場合はラベル表示へ切り替える導線を示す。

## 表示方法

「すべて線で接続」を初期表示とし、「ラベルで接続」へ切り替えられる。

- Aの非ゼロ成分：状態信号 → 係数ブロック → 対応する状態の加算点。
- Bの非ゼロ成分：外部入力 → 係数ブロック → 対応する状態の加算点。
- 加算点 → 積分器 → 状態信号。
- CとDの非ゼロ成分：各状態信号／外部入力 → 係数ブロック → 出力加算点 → 出力。
- 加算点は白丸。係数の負号は係数ブロック内に残す。
- 入力を最初の層、出力を最後の層に置き、積分器・入力・出力の経路を優先して帰還を配置する。
- 状態信号は `x₁(s)`、`x₂(s)`、`x₃(s)` と表し、掛け算との混同を避ける。
- 真の分岐点を黒丸で表示。黒丸のない交差は接続しない。交差では白い下地を使う。
- 図は計算結果の下で横幅全体を使い、拡大縮小・全体表示・PNG/SVG保存が可能。

## 伝達関数の表示

内部の厳密計算用の正規化と、人が読む表示を分離した。表示時には分子・分母の有理係数を同時に通分し、共通の整数係数を除き、分母のsの最高次項の符号を正にする。sの降べき順に数式を表示する。文字係数では割らない。

例えば `1 / (−s²/2 + 5s/2 − 3)` は `−2 / (s² − 5s + 6)` と表示する。数式表示と結果のテキスト・コピーに同じ整数係数の分数を使い、有理式としての等価性は厳密に検証する。

## 検証範囲

状態数1・2、密な3次行列、全係数0を対象に、非ゼロ成分と配線の対応、ノードの重なり、直角配線、異なる信号の線分の重なりを検証する。同一信号の共通幹と直交する交差は別に扱う。複雑なグラフですべての交差をなくす保証はない。
