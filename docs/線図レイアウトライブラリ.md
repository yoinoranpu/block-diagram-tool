# 自作の主経路配置と因数形表示

## 配置処理

ELK.js依存と配布Workerを削除し、このアプリ用に配置処理を書き直した。外部の配置コードの複製や移植は行っていない。React・数式表示・記号計算など、従来から利用している汎用ライブラリは引き続き利用する。

1. 入力から出力へ到達する単純経路を探索する。状態空間線図では積分器を多く含む経路を優先し、Dの直達経路だけを主経路にしない。
2. 選んだ主経路を左から右の一直線に置く。
3. それ以外の要素を接続成分に分け、帰還を下側、並列・出力分岐を上側の専用レーンに置く。経路の区間が重なるものは別の段に分ける。
4. 既存の自作直角配線処理で接続する。まっすぐ結べる場合は直線を優先し、障害物・別信号の重なりを避け、不要な同一直線上の折れ点を除く。
5. 真の分岐点のみ黒丸で示す。交差だけの線には黒丸を付けない。

状態空間表現の全接続表示に加え、通常の「線図を整える」と伝達関数からの積分器線図生成にも適用する。入力から出力に到達しない未完成の線図等には従来の配置を残す。ラベル接続表示への切替も維持する。

長い主経路を折り返さないために描画領域を拡張した。座標は0〜10000の範囲で保存でき、パン・拡大縮小・全体表示・移動・複製・線の途中への追加を利用できる。従来のJSONも読み込める。

密な行列などではすべての交差を除く保証はない。自動配線ができない場合はその旨を表示する。線図の配置を変えても、信号の接続・入力符号・伝達関数は変えない。

## 因数形の数式表示

表示する分子・分母は整数係数にそろえたうえで、既存の記号計算ライブラリによる因数分解を試す。因数形を展開した多項式と元の多項式を自作の厳密演算で比較し、一致した場合のみ表示する。因数分解できない場合・表現が未対応の場合は展開形に戻す。

例：`−2 / (s² − 5s + 6)` は既定で `−2 / ((s−2)(s−3))` と表示する。「展開形を表示」から降べき順の形も見られる。内部の計算値は変えず、テキスト式・コピーは従来どおり等価な展開形を提供する。負の因子や因子のべき乗も括弧を保持して表示する。

## 検証

主経路の全要素の中心が同じ高さにあること、その経路上の配線に折れ点がないことを検証する。状態数1・2、密な3次行列、全係数0について、非ゼロ成分の配線、ノードの分離、直角配線、別信号同士の線分の分離を検証する。通常の直列・並列・帰還・複数ループの整列後の伝達関数も厳密比較する。
